## LMS Skills

When helping with LMS-related queries, follow the guidelines in `skills/lms/SKILL.md`:

- Ask which lab when the user does not specify (especially for scores, pass rates, timelines)
- Format numeric results nicely (percentages with %, rounded to 1-2 decimals)
- Use tables for structured data
- When the user asks "what can you do?", explain you can query the LMS for labs, learners, scores, timelines, groups, and completion rates
